# Kafe Adisyon Sistemi

Tek şubeli bir kafe için yerel ağda çalışan adisyon ve satış noktası (POS) uygulaması.

Uygulama buluta bağımlı değildir. Kasa bilgisayarında çalışır; telefon, tablet ve
diğer bilgisayarlar aynı yerel ağ üzerinden kasa bilgisayarının IPv4 adresine bağlanır.

Kurulum, çalıştırma ve geliştirme adımları Phase 0 ile birlikte bu dosyaya eklenecektir.
